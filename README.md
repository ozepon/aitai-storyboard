# Storyboard

ショート動画の撮影現場で使う構成ビューアーアプリです。
スマホのブラウザで開いて、構成JSONを読み込むだけで使えます。

---

## どんなアプリ？

撮影構成（カット割り・テロップ・撮影のコツ）をスマホで見ながら撮影を進めるためのツールです。

できること：

- 構成カードを1枚ずつ確認しながら撮影を進める
- カットごとにチェックを入れて進捗を管理する
- カットごとにメモを残す（気づき・変更点・トラブルなど）
- 全体メモを書いて作業報告としてまとめる
- 作業報告をワンタップでコピーしてLINEなどで送れる
- キャプション（Instagram投稿文）をコピーできる

---

## 使い方

1. `index.html` をスマホのブラウザで開く
2. 「JSONファイルを選択」から構成JSONを読み込む
3. 店舗タブを切り替えながら撮影を進める
4. 撮影が終わったカットにチェックを入れる
5. 気になった点があればカットのメモに記入する
6. 全店舗の撮影が終わったら「作業報告」ボタンから報告をコピーしてLINEで送る

## データの取り扱いについて

### すべてのデータはあなたのスマホの中だけにあります

このアプリはサーバーを使っていません。
HTMLファイル1つで動く完全ローカルのアプリです。

- 構成データ（JSON）はスマホのブラウザに読み込まれるだけで、どこにも送信されません
- チェック状態・メモ・作業報告はブラウザの「localStorage」に保存されます
- localStorageはそのスマホのそのブラウザの中だけに存在するデータ領域です
- インターネットには一切接続しません。Wi-Fiが切れていても動きます

### データは自分で共有しないかぎり、どこにも共有されません

- メモや作業報告は「コピー」ボタンでクリップボードにコピーされるだけです
- LINEやメールに自分で貼り付けて送らないかぎり、他の人には見えません
- 逆に言えば、スマホを機種変更したりブラウザのデータを消すとメモは消えます

### データが消えるケース

以下の場合、保存されたチェック・メモは消えます：

- ブラウザの「履歴」や「Webサイトデータ」を削除した場合
- ブラウザのプライベートモード（シークレットモード）で開いた場合
- 別のブラウザで開いた場合（Safariで保存したデータはChromeでは見えません）
- スマホを初期化した場合

大事なメモは撮影後に作業報告としてコピー・送信しておくことをおすすめします。

## 技術メモ（開発者向け）

- HTML / CSS / JavaScript のみで構成。外部ライブラリなし
- データ永続化は localStorage を使用
- storageキーは `storyboard_{モール名}_{タイトル}_{作成日}` で生成
- 全体メモは `storyboard_general_{同上}` で別途保存
- 読み込み履歴は `storyboard_history` に最大10件保持（JSONスナップショット含む）
- 構成JSONのスキーマは sample_data.json を参照
